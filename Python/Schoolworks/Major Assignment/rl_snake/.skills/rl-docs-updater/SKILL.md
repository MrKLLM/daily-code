# RL Snake 文档更新 Skill

自动维护 rl_snake 项目的三个核心文档，确保代码与文档同步。

## 触发条件

- 功能变更后
- Bug修复后（同步修复说明）
- 新功能完成后（更新使用说明）
- 解决重大问题后（生成分析报告）

## 文档路径

| 文档 | 路径 | 内容 |
|------|------|------|
| README | `rl_snake/README.md` | 项目简介、安装、使用方法 |
| 技术文档 | `rl_snake/docs/技术实现文档.md` | 代码结构、API、实现细节 |
| RL原理 | `rl_snake/docs/强化学习原理与实现.md` | 算法原理、公式推导 |

## 更新流程

1. 读取当前代码变更内容
2. 识别影响的文档章节
3. 同步更新对应文档
4. 如有重大问题，生成分析报告到 `docs/` 目录

## 报告格式（重大问题）

```markdown
# 问题分析报告 - [日期]
## 问题描述
## 根因分析
## 修复方案
## 验证结果
```
