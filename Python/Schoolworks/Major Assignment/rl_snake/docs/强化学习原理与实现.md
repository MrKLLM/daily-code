# 强化学习原理与实现

## 1. 什么是强化学习

强化学习（Reinforcement Learning, RL）是机器学习的三大范式之一（另外两个是监督学习和非监督学习）。

核心思想：**智能体（Agent）在环境（Environment）中不断试错，根据奖励信号学习最优行为策略。**

与监督学习的区别：
- 监督学习：有"标准答案"（标签），模型学习输入→输出的映射
- 强化学习：没有标准答案，只有"奖励反馈"，模型自己探索出好的策略

类比：像训练一只小狗 —— 做对了给零食（正奖励），做错了不给或轻微惩罚（负奖励），小狗最终学会什么行为能获得最多零食。

## 2. 基本概念

### 2.1 核心要素

| 概念 | 英文 | 含义 | 本项目体现 |
|------|------|------|-----------|
| 智能体 | Agent | 做决策的"大脑" | `DQNAgent` 类 |
| 环境 | Environment | 智能体所处的世界 | `SnakeGame` 类 |
| 状态 | State | 环境当前的情况 | 13 维特征向量 |
| 动作 | Action | 智能体可以做的事 | 0=直行, 1=右转, 2=左转 |
| 奖励 | Reward | 环境给的反馈信号 | 吃食物+10, 撞墙-10, 走一步-0.01 |
| 策略 | Policy | 状态→动作的映射规则 | Q 网络的 argmax |
| 价值函数 | Value | 预期累计奖励 | Q(s, a) |

### 2.2 交互循环

```
┌──────────┐  action a   ┌──────────────┐
│  Agent   │ ──────────► │  Environment │
│ (大脑)   │             │  (贪吃蛇)    │
└────┬─────┘             └──────┬───────┘
     │                          │
     │    reward r, state s'    │
     ◄──────────────────────────┘
     │
     ▼
  更新策略（学习）
```

每一步：
1. 智能体观察当前状态 s
2. 根据策略选择动作 a
3. 环境执行动作，返回新状态 s' 和奖励 r
4. 智能体根据 (s, a, r, s') 更新策略

## 3. 马尔可夫决策过程 (MDP)

强化学习的数学基础是**马尔可夫决策过程**，由五元组定义：

```
(S, A, P, R, γ)
```

| 符号 | 含义 | 本项目 |
|------|------|--------|
| S | 状态空间 | 所有可能的 13 维向量 |
| A | 动作空间 | {0, 1, 2}（直行、右转、左转） |
| P | 状态转移概率 | 确定性环境，P=1 |
| R | 奖励函数 | 见奖励设计表 |
| γ | 折扣因子 | 0.9 |

**马尔可夫性质**：下一个状态只取决于当前状态和动作，与历史无关。本项目满足这个性质——蛇的下一步只取决于当前位置和方向。

## 4. Q-Learning 算法

### 4.1 核心思想

学习一个**动作价值函数** Q(s, a)：在状态 s 下执行动作 a，之后能获得的**累计折扣奖励期望**。

```
Q(s, a) = E[ r₁ + γr₂ + γ²r₃ + ... | s₀=s, a₀=a ]
```

一旦学到了准确的 Q 函数，最优策略就是：在每个状态下选 Q 值最大的动作。

### 4.2 Bellman 方程

Q 函数满足递推关系：

```
Q(s, a) ← Q(s, a) + α [ r + γ · max Q(s', a') - Q(s, a) ]
                        └───── TD 目标 ─────┘   └─ 当前估计 ┘
```

- **TD 目标**：`r + γ · max Q(s', a')` —— 对 Q 值的"更好估计"
- **TD 误差**：`TD目标 - 当前估计` —— 估计的偏差
- **学习率 α**：控制更新步长

### 4.3 传统 Q-Learning 的局限

当状态空间很大时（比如 Atari 游戏的像素输入），无法用表格存储每个 (s, a) 的 Q 值。

解决方案：**用神经网络近似 Q 函数** —— 这就是 DQN。

---

## 5. DQN — 深度 Q 网络

### 5.1 基本思想

用神经网络 Q(s, a; θ) 拟合 Q 函数，其中 θ 是网络参数。

训练目标：让网络输出的 Q 值逼近 Bellman 方程中的 TD 目标。

```
网络输入:  状态 s（13维向量）
网络输出:  每个动作的 Q 值（3个数）
损失函数:  (Q网络输出 - TD目标)²
```

### 5.2 三大关键技术

DQN 在普通 Q-Learning 的基础上引入三个 trick，解决了训练不稳定的问题：

#### 技巧一：经验回放 (Experience Replay)

**问题**：相邻样本高度相关（连续几步的状态很相似），普通 SGD 容易过拟合。

**解决**：把每一步的经验 (s, a, r, s', done) 存进一个缓冲区，训练时**随机采样**一个小批量。

```python
# 存入经验
replay_buffer.push((state, action, reward, next_state, done))

# 训练时随机采样
batch = random.sample(replay_buffer, batch_size=64)
```

好处：
1. 打破时间相关性
2. 一份数据可被多次利用，提高样本效率

**本项目实现**：`ReplayBuffer` 类，容量 10 万条，deque 循环队列。

#### 技巧二：目标网络 (Target Network)

**问题**：TD 目标 `r + γ · max Q(s', a')` 中的 Q 也在持续变化——用不断变化的目标去训练自己，容易振荡。

**解决**：维护两个网络：
- `policy_net`：在线学习，每步更新
- `target_net`：固定不动，定期从 policy_net 同步

```python
# 每 100 步同步一次
if step % 100 == 0:
    target_net.load_state_dict(policy_net.state_dict())
```

好处：TD 目标在一段时间内保持固定，训练更稳定。

#### 技巧三：ε-贪心探索 (Epsilon-Greedy)

**问题**：强化学习需要在"利用已知最佳动作"和"探索新动作"之间平衡。

**解决**：以 ε 概率随机选动作，1-ε 概率选 Q 值最大的动作。

```python
if random.random() < epsilon:
    action = random.randint(0, 2)    # 探索：随机
else:
    action = Q_values.argmax()        # 利用：贪心
```

ε 从 1.0 开始（100% 随机），逐渐衰减到 0.01（几乎纯贪心）。

**本项目参数**：
- `epsilon_start = 1.0`
- `epsilon_end = 0.01`
- `epsilon_decay = 0.999`（每回合乘以 0.999）

### 5.3 DQN 完整算法

```
1. 初始化:
   - 创建 policy_net 和 target_net（权重相同）
   - 创建经验回放缓冲区
   - ε = 1.0

2. for episode = 1 to N:
     s = env.reset()
     while not done:
       a = ε-贪心选动作
       s', r, done = env.step(a)
       存入 (s, a, r, s', done) 到缓冲区
       
       从缓冲区随机采样 64 条:
         计算 q_pred = Q_policy(s, a)
         计算 q_target = r + γ * max Q_target(s')
         loss = HuberLoss(q_pred, q_target)
         反向传播更新 policy_net
       
       每 100 步: policy_net → target_net
       衰减 ε
       s = s'
```

## 6. 本项目的具体实现

### 6.1 状态设计（13 维）

为什么不直接用游戏画面？因为：
1. 13 维向量训练极快（毫秒级）
2. 手工特征包含了关键信息，学习效率高
3. 不需要 GPU，普通 CPU 即可

```python
state = [
    # 三个方向的危险检测（相对方向）
    int(前方有障碍),      # [0]
    int(右转有障碍),     # [1]
    int(左转有障碍),     # [2]
    # 当前朝向（one-hot）
    int(朝左), int(朝右), int(朝上), int(朝下),  # [3-6]
    # 食物相对位置
    int(食物在左), int(食物在右),                 # [7-8]
    int(食物在上), int(食物在下),                 # [9-10]
    # 食物距离（归一化）
    food_dx,  # 食物x方向距离（-1到1）          # [11]
    food_dy,  # 食物y方向距离（-1到1）          # [12]
]
```

**为什么用相对方向？** 因为"前方有障碍就转弯"这个规则，无论蛇朝哪个方向都成立。用相对方向能让模型学到更通用的策略。

### 6.2 动作设计（3 个）

为什么不直接用 4 个方向（上/下/左/右）？

因为当蛇朝右时，"朝左"是 180° 掉头——这等于自杀。用相对动作（直行/左转/右转）天然避免了这个问题。

### 6.3 奖励塑形 (Reward Shaping)

奖励是 RL 学习的"指挥棒"：

| 事件 | 奖励 | 目的 |
|------|------|------|
| 吃到食物 | +10 | 强烈正反馈，鼓励得分 |
| 撞墙/撞自己 | -10 | 强烈负反馈，避免死亡 |
| 走一步没吃到食物 | -0.01 | 小惩罚，鼓励高效路径 |
| 超时未吃到食物 | -10 | 防止蛇原地打转浪费时间 |

**关键设计**：每步 -0.01 的小惩罚让 AI 学会"走最短路径吃食物"，而不是漫无目的地游荡。

### 6.4 网络结构

```python
QNetwork(
    Linear(13, 256) → ReLU    # 第一层：13维→256维
    Linear(256, 256) → ReLU   # 第二层：256维→256维
    Linear(256, 3)             # 输出层：256维→3个Q值
)
```

为什么是 256？经验值——对于 13 维输入，256 单元的两层网络足够拟合 Q 函数，再大反而浪费计算资源。

### 6.5 损失函数

使用 **Huber Loss**（也叫 Smooth L1 Loss），而非普通 MSE：

```
Huber Loss = {
    0.5 * error²,                  if |error| ≤ 1
    |error| - 0.5,                 otherwise
}
```

好处：对异常值（如偶尔的 -10 大惩罚）更鲁棒，不会因单个大误差导致梯度爆炸。

### 6.6 训练效果

| 训练阶段 | 典型表现 |
|----------|----------|
| 0-100 回合 | 随机游走，平均分 ~0.5 |
| 100-300 回合 | 开始学会避障，平均分 1-3 |
| 300-500 回合 | 稳定得分，平均分 5-10 |
| 500+ 回合 | 策略成熟，平均分 10+ |

## 7. 算法对比

### 7.1 为什么不用其他算法？

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| Q-Learning | 表格方法，无法处理连续状态 | 状态空间小 |
| DQN | 值函数方法，适合离散动作 | 本项目（离散动作 3 个） |
| PPO | 策略梯度，更稳定 | 连续动作空间 |
| A2C | Actor-Critic，可并行 | 大规模环境 |

本项目选 DQN 的原因：
1. 动作空间小（3 个），DQN 足够
2. 实现简单，适合教学
3. 训练快，CPU 即可

### 7.2 可扩展方向

- **Double DQN**：解决 Q 值过估计
- **Dueling DQN**：分离状态价值和优势函数
- **Prioritized Replay**：重要样本加权采样
- **Rainbow DQN**：以上多种改进的组合

## 8. 关键公式汇总

### Bellman 方程
```
Q(s,a) = r + γ · max Q(s',a')
```

### DQN 损失函数
```
L(θ) = E[ (r + γ · max Q(s',a';θ⁻) - Q(s,a;θ))² ]
         └──── TD 目标（θ⁻固定）────┘  └─ 当前估计 ┘
```

### ε-贪心策略
```
a = { random action,    with probability ε
    { argmax Q(s,a;θ),  with probability 1-ε
```

### 指数衰减
```
ε = max(ε_end, ε × ε_decay)
```

### 折扣累计奖励
```
G_t = r_t + γr_{t+1} + γ²r_{t+2} + ... = Σ γᵏr_{t+k}
```

## 9. 总结

本项目通过 DQN 算法，让 AI 在贪吃蛇环境中**完全自主学习**：

1. **无需人工指导**：AI 不知道"什么是好的策略"，只通过奖励信号学习
2. **试错学习**：早期随机探索（ε=1.0），逐渐利用已学知识（ε→0.01）
3. **经验积累**：通过经验回放，每份数据被多次利用
4. **稳定训练**：目标网络固定学习目标，避免振荡

最终 AI 能自动学会：朝食物移动、避开墙壁和自身、高效吃食物。这就是强化学习的魅力——**让机器自己学会解决问题**。
