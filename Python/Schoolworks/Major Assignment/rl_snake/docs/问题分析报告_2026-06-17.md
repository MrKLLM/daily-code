# 问题分析报告 - 2026-06-17

## 问题描述

训练前10轮得分几乎为0（仅第3轮得1分），AI无法学会吃食物。

## 根因分析

### 1. 状态空间信息不足
- 原状态只有11维，缺少食物距离信息
- 20x20网格中，蛇头到食物可能很远，但网络不知道距离多远
- 仅知道"食物在左/右/上/下"，无法判断远近

### 2. ε衰减过快
- `epsilon_decay=0.995`，10轮就从1.0降到0.13
- 探索时间严重不足，AI还没学到有效策略就进入 exploitation 阶段

### 3. 每步惩罚过大
- 每步-0.1惩罚 × 20x20地图的步数 = 累积惩罚很大
- 容易学不到正向策略

### 4. 地图偏大
- 20x20=400格，对DQN+简单状态来说太大
- 状态空间复杂度随地图面积指数增长

## 修复方案

| 修改项 | 原值 | 新值 | 原因 |
|--------|------|------|------|
| grid_size | 20 | 10 | 缩小地图降低复杂度 |
| STATE_SIZE | 11 | 13 | 增加距离特征 |
| epsilon_decay | 0.995 | 0.999 | 延长探索时间 |
| 每步惩罚 | -0.1 | -0.01 | 减小累积惩罚 |

### 新增状态特征
```python
food_dx = (food_x - head_x) / grid_size  # 归一化距离
food_dy = (food_y - head_y) / grid_size
```

## 验证方法

运行 `python train.py --episodes 50 --grid-size 10`，观察：
1. 前10轮是否能吃到食物
2. 平均分是否逐步提升
3. ε衰减是否更平缓

## 预期效果

- 50回合内应能看到稳定得分
- 平均分应从~0.5提升到3-5
- 训练曲线应呈现上升趋势
