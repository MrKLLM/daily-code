# 贪吃蛇强化学习项目 — 技术实现文档

## 1. 项目总览

本项目使用 **DQN（Deep Q-Network）** 算法训练一个贪吃蛇 AI，使其自动学会吃食物、避开墙壁和自身。整个项目采用模块化结构，代码分离为游戏环境、智能体、训练流程、可视化测试四个部分。

## 2. 游戏环境 — `game/snake_game.py`

### 2.1 核心类 `SnakeGame`

这是整个项目的基石，封装了贪吃蛇的完整逻辑，并提供 Gym 风格的 API（`reset()` / `step()` / `get_state()`）。

#### 关键属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `grid_size` | int | 网格行列数，默认 10×10 |
| `cell_size` | int | 每格像素大小，默认 30 |
| `speed` | int | 帧率（越大动画越快） |
| `render_mode` | bool | 是否开启 Pygame 可视化 |
| `STATE_SIZE` | int | 状态空间维度 = 13 |
| `ACTION_SPACE_SIZE` | int | 动作空间大小 = 3 |

#### 状态变量

```python
self.snake: deque       # 蛇身坐标队列，snake[0] 是蛇头
self.food: tuple        # 食物坐标 (x, y)
self.direction: int     # 当前朝向（0=右, 1=上, 2=左, 3=下）
self.score: int         # 当前得分
self.frame_iteration: int       # 本回合已走步数
self.steps_without_food: int    # 距上次吃到食物的步数
```

### 2.2 Gym 风格 API

#### `reset() -> np.ndarray`

重置环境到初始状态：
1. 蛇放置在地图中央，长度为 3，初始朝右
2. 随机放置食物
3. 返回初始状态向量（13 维）

#### `step(action) -> (state, reward, done, info)`

执行一步动作：

```
action: 0=直行, 1=右转, 2=左转
```

内部流程：
1. 根据 action 更新蛇的朝向
2. 计算新蛇头位置
3. 碰撞检测（撞墙 / 撞自己 / 超时）
4. 移动蛇身
5. 判断是否吃到食物
6. 返回 (新状态, 奖励, 是否结束, 附加信息)

#### `get_state() -> np.ndarray`

返回 13 维特征向量：

```
[0]  前方是否有障碍    [1]  右转方向是否有障碍    [2]  左转方向是否有障碍
[3]  当前朝左          [4]  当前朝右              [5]  当前朝上
[6]  当前朝下          [7]  食物在左侧            [8]  食物在右侧
[9]  食物在上方        [10] 食物在下方
[11] 食物x方向距离     [12] 食物y方向距离
```

### 2.3 奖励设计

| 事件 | 奖励值 | 设计目的 |
|------|--------|----------|
| 吃到食物 | +10 | 强烈鼓励得分 |
| 撞墙 / 撞自己 | -10 | 强烈惩罚死亡 |
| 走一步没吃到食物 | -0.01 | 鼓励高效吃食物 |
| 超时未吃到食物 | -10 | 防止原地打转 |

### 2.4 方向系统

使用**相对动作**而非绝对方向：

```python
# 方向枚举（顺时针顺序）
RIGHT = 0, UP = 1, LEFT = 2, DOWN = 3

# 动作映射
0 = 直行（方向不变）
1 = 右转（顺时针 +1）
2 = 左转（逆时针 -1）
```

这样设计的好处：模型只需判断"当前姿态下该直行还是转弯"，避免了"掉头自杀"等冗余决策。

### 2.5 Pygame 渲染

渲染模块实现了现代深色主题 UI：
- **棋盘格背景**：深色交替方块 + 细网格线
- **脉冲发光食物**：三层圆形叠加 + 高光点，sin 波驱动半径脉动
- **渐变蛇身**：蛇头亮蓝带眼睛，身体从亮绿渐变到深绿
- **右侧信息面板**：显示 SCORE、BEST、LENGTH、STEPS、EPISODE、DIRECTION

### 2.6 手动游戏模式

`human_play()` 函数支持键盘控制：
- 方向键 ↑↓←→ 控制移动
- ESC 退出
- 游戏结束后自动重启

## 3. DQN 智能体 — `agent/dqn_agent.py`

### 3.1 Q 网络结构

```python
QNetwork(
    Linear(13, 256) -> ReLU
    Linear(256, 256) -> ReLU
    Linear(256, 3)          # 输出 3 个动作的 Q 值
)
```

- 输入：13 维状态向量
- 输出：3 个动作的 Q 值（直行、右转、左转）
- 隐藏层：两层 256 单元的全连接网络

### 3.2 经验回放缓冲区 `ReplayBuffer`

```python
class ReplayBuffer:
    def __init__(self, capacity=100_000):
        self.buffer = deque(maxlen=capacity)  # 循环队列

    def push(self, transition):
        # transition = (state, action, reward, next_state, done)
        self.buffer.append(transition)

    def sample(self, batch_size):
        # 随机采样，打破时间相关性
        batch = random.sample(self.buffer, batch_size)
        # 解包为 numpy 数组
        return states, actions, rewards, next_states, dones
```

容量 10 万条，超过后自动丢弃最旧样本。

### 3.3 DQN 智能体核心逻辑

#### 初始化

```python
DQNAgent(
    state_size=11,           # 状态维度（13维）
    action_size=3,           # 动作数量
    hidden_size=256,         # 隐藏层大小
    lr=1e-3,                 # 学习率
    gamma=0.9,               # 折扣因子
    epsilon_start=1.0,       # 初始探索率
    epsilon_end=0.01,        # 最终探索率
    epsilon_decay=0.995,     # 衰减系数
    buffer_size=100_000,     # 经验池容量
    batch_size=64,           # 批量大小
    target_update_every=100, # 目标网络同步频率
)
```

创建两个网络：`policy_net`（在线学习）和 `target_net`（固定目标）。

#### `act(state, training)` — 动作选择

```python
def act(self, state, training=True):
    if training and random.random() < self.epsilon:
        return random.randint(0, 2)     # ε 概率随机探索
    # 否则选 Q 值最大的动作
    q_values = self.policy_net(state)
    return q_values.argmax()
```

#### `learn()` — 学习更新

核心流程：
1. 从经验池采样 64 条数据
2. 计算当前 Q 值：`q_pred = Q_policy(s, a)`
3. 计算 TD 目标：`q_target = r + γ * max Q_target(s')`
4. Huber Loss 反向传播
5. 梯度裁剪（max_norm=10）
6. 每 100 步同步 policy_net → target_net
7. 衰减 ε

### 3.4 模型保存与加载

```python
# 保存（包含 4 个组件）
torch.save({
    "policy_net":  策略网络权重,
    "target_net":  目标网络权重,
    "optimizer":   优化器状态,
    "epsilon":     当前探索率,
}, path)

# 加载（评估时可跳过 optimizer）
agent.load(path, load_optimizer=False)
agent.epsilon = 0.0  # 纯贪心，不再随机
```

## 4. 训练流程 — `train.py`

### 4.1 训练循环

```
for episode in 1..500:
    state = env.reset()
    while not done:
        action = agent.act(state)          # ε-贪心选动作
        next_state, reward, done, info = env.step(action)
        agent.remember(state, a, r, s', done)  # 存经验
        agent.learn()                      # 采样更新
        state = next_state
    # 记录统计信息
    if score > best_score:
        agent.save("models/snake_dqn.pth")
```

### 4.2 统计记录

每 10 回合打印：
- 当前得分、近 20 回合平均分、历史最高分
- 当前 ε 值、平均 loss、步数、用时

训练结束后保存：
- `models/snake_dqn.pth` — 最优模型
- `models/snake_dqn_final.pth` — 最终模型
- `logs/training_curve.png` — 训练曲线（得分、loss、ε）
- `logs/training_log.csv` — 每回合详细数据

## 5. 可视化测试 — `play.py`

### 5.1 使用方法

```bash
python play.py --model models/snake_dqn.pth --episodes 5
```

### 5.2 运行逻辑

1. 创建游戏环境（开启渲染）
2. 创建 DQN 智能体，加载训练好的权重
3. 设置 `epsilon = 0`（纯贪心，不再随机探索）
4. 运行 N 回合，每回合结束后打印得分
5. 输出统计摘要（平均分、最高分、最低分）

### 5.3 命令行参数

```bash
--model      模型文件路径（默认 models/snake_dqn.pth）
--episodes   测试回合数（默认 3）
--speed      动画帧率（默认 10）
--cell-size  格子像素大小（默认 30）
```
